# AI Act Copilot: final POC snapshot

Evros Labs · v0.1.6-poc.1

A limited end-to-end demo: Python source, two local model calls, selected legal
passages, checked source/citation evidence and a context question.

Extension 0.1.6; Python engine 0.1.0; result schema 1.0; prompt poc-4.

## Changes

- Clearer README explaining the two passes, six-passage corpus, template
  questions, demo scope and the explicit corpus verification command.
- Shorter setup using uv run without manual environment activation.
- VS Code workspace and packaged guide point to the uv engine environment.
- Writing instruction to avoid em dashes recorded in AGENTS.md.

## Install

Install uv and Ollama separately. From a source checkout, run the README's
model download and uv scan commands. Install ai-act-copilot-0.1.6.vsix through
VS Code's Install from VSIX action, then reload the window. The release also
includes the unchanged engine 0.1.0 wheel and SHA256SUMS.txt.

## Scope

Private POC pre-release. Six legal passages, bounded Python input and partly
curated question/explanation wording. The update command verifies existing
passages; it does not replace changed law automatically. No compliance
certification, Gemini provider, Marketplace or PyPI publication.

This snapshot does not close the remaining manual editor acceptance gates in
Linear. Validation details are recorded in docs/VERIFICATION.md.
