# AI Act Copilot — POC pre-release

**Evros Labs · v0.1.5-poc.1**

This is a private, local-first prototype for engineering review of Python AI use.
It is not a legal compliance certificate or a production release.

## Included

- Installable Python engine/CLI: `aiact scan`, `doctor`, explicit `update`.
- Native VS Code diagnostics, hover and report; source and official-source links.
- Local setup health panel and explicit integrated-terminal Ollama startup.
- Opt-in debounced on-save review, cancellation, trust and stale-result guards.
- Two bounded local model passes using the tested `qwen2.5:3b` tag.
- Reviewed official-source subset, deterministic retrieval and exact evidence checks.
- Five demonstration cases, Evros Labs branding and beginner/settings guides.

Component versions: VS Code extension **0.1.5**, Python engine **0.1.0**,
ScanResult schema **1.0**, prompt **poc-4**.

This release fixes explicit Ollama binary selection, fallback to a system
installation when the local bundle is absent, custom loopback startup ports and
workspace substitution for explicit corpus paths.

## Install

Download the `.vsix`, Python `.whl` and `SHA256SUMS.txt` assets. Verify files with
`shasum -a 256 -c SHA256SUMS.txt` (macOS) or `sha256sum -c SHA256SUMS.txt` (Linux).
Install the wheel in a Python 3.11+ environment and the VSIX through VS Code's
Install from VSIX action. Install Ollama and explicitly pull `qwen2.5:3b` during
setup. The extension never downloads a model automatically.

Open the project root, configure the Python CLI path, check Local setup, then
review `examples/recruitment/ranker.py`. See the root README and extension
introduction for complete Settings UI / JSON examples.

## Validation and limits

Current release validation is recorded in `docs/VERIFICATION.md`.
Historical five-case local/offline checks passed with exact source/legal evidence.
Release checks passed: 44 engine tests, 20 extension tests, TypeScript compilation,
VSIX packaging and installation, wheel contents and live local health. A fresh
loopback-only recruitment scan completed with one finding and no operational
errors (68,080 ms on the documented Mac). Native UI
rendering, keyboard/theme and complete editor lifecycle acceptance remain a
manual checklist. A POC release does not close the full Linear milestone.

Only bounded Python input and six reviewed passages are supported. Initial
context explanations/questions use reviewed wording because unconstrained small
model prose was unreliable in earlier tests. No full legal applicability, risk
classification or completeness guarantee is made. Scans stay local; setup and
explicit legal refresh can require network access. Corpus refresh verifies the
reviewed subset and requires manual review if passages change.

No PyPI/Marketplace publication, new publisher registration, automatic legal
monitoring, cloud fallback or OS login service is included. Repository visibility
remains private. No open-source license has been selected.
