# AI Act Copilot: presentation POC

Evros Labs · v0.1.6-poc.4

Final limited end-to-end POC accepted by the user for presentation on
29 October 2026. Extension 0.1.6; engine 0.1.0; result schema 1.0; prompt poc-4.

This snapshot includes the release changelog and versioning rules, on top of
the uv setup, explanatory diagrams, mascot, VSIX installation guide and GitHub
Actions test/package pipeline from v0.1.6-poc.3. Runtime behavior is unchanged.

Download the VSIX, Python wheel and SHA256SUMS.txt assets. Follow README.md for
setup; install the VSIX through VS Code's Install from VSIX action. Ollama and
its model remain explicit local prerequisites.

The demo supports selected Python examples and six saved legal passages. It
uses partly curated explanations/questions. It is not full legal coverage or
compliance certification. Gemini and automatic legal text replacement remain
future features. Detailed native editor checks are not independently recorded;
the POC is closed on the user's presentation acceptance.

See CHANGELOG.md and [historical verification](https://github.com/for-aiur/ai-act-copilot/blob/v0.1.6-poc.4/docs/VERIFICATION.md) for recorded checks and scope.
